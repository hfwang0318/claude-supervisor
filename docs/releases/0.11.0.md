# code-supervisor 0.11.0

## Highlights

- Linux probe isolation via bubblewrap, with an opt-in Docker/Podman fallback and a safe read-only fallback.
- `linux-preflight.mjs` and `linux-selftest.mjs` for host capability and isolation checks.
- Probe contract carries optional `location`, `current`, and `required`; reviewer findings require concrete current-versus-required values.
- Contract probes and repository-command grounding for reviewer findings.
- `/code-supervisor health` reports mode, model, host version, output profile, warnings, open issues, and the last side call.
- Final review jobs can survive main-generation invalidation; stale results still cannot commit verified evidence.
- Side-model output-profile warnings when semantic review is enabled but the selected model has no transport profile.
- Linux and reviewer evaluation evidence under `docs/evals/2026-10-20-linux-reviewer-results.md`.

## Verification

- 360 plugin tests pass.
- `node scripts/check.mjs` passes.
- Linux: plugin tests, bwrap/container isolation, probe verification, gate, and repair paths exercised in containers.
- Live cba silent-mutant task with `supervise` + `glm-5.3-flash`: official 3/3 pass; baseline mutant 0/3.

## Known limits

- One live graded task; no same-session off arm, so causal attribution is not isolated.
- Some samples are constructed mutants or truncated real patches.
- One-shot `claude -p` still ends before a turn-end side call can complete; persistent/interactive sessions are required for reviewer evaluation.
- The reviewer still misses some hidden-contract defects.
